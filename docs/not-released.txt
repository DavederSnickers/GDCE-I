# What is deliberately NOT published, and why.
#
# Two files are published under a different name because their working-tree name
# or their hardcoded paths would mislead a reader.  make_release.sh does the
# rename and prints the sed rules it applied:
#   src/smoke_build_dataset.py -> src/build_dataset.py
#       it is not a smoke test, it is the dataset build step of the pipeline
#   train_shared_judges.py     -> src/shared_judge/train_judges_nonmol.py
#       moved next to train_judge.py, with the two hardcoded paths replaced by
#       $GDCE_DATA / $GDCE_JUDGES and the import fixed for the new location
#
#
# This file is the audit trail for the release: anybody (including a reviewer)
# can check that nothing relevant to the paper was dropped, and that nothing
# irrelevant was pushed.  Sizes are from 2026-11-05.
